# UI-UX-Experiment3

## Aim:
To design a Retail Mobile Application UI using Figma, which allows users to browse products, explore categories, view product details, select product colours, and add products to the shopping cart.
## Algorithm:
1. Open Figma and create a new design file.
2. Create three mobile screens: Home Page, Categories Page, and Product Details Page.
3. Design the home page with a search bar, promotional banner, categories, and trending deals.
4. Design the categories page with product categories and product cards.
5. Create the product details page with product image, name, price, rating, and description.
6. Add colour selection, quantity selection, and Add to Cart button.
7. Apply suitable colours, fonts, icons, and spacing to make the application user-friendly.
